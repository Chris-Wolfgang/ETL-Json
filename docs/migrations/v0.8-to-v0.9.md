# Migrating from v0.8 to v0.9

## Prerequisites

Install the new NuGet package:

```
dotnet add package Wolfgang.Etl.Json --version 0.9.0
```

v0.9 references `Wolfgang.Etl.Abstractions` 0.24, which introduces the per-stage-kind base records (`ExtractorOptions`, `LoaderOptions`) that this release builds on. Pre-1.0: breaking changes are listed here rather than deferred to a major version.

---

## Breaking Changes

| API | Before | After | Reason |
|-----|--------|-------|--------|
| `JsonLineLoader<T>`, `JsonSingleStreamLoader<T>`, `JsonMultiStreamLoader<T>` | implement `ISupportDryRun` | do not | Abstractions 0.24 removes the interface; dry run is construction-time configuration through the loader's options record (ADR-0009) |
| The `JsonSerializerOptions` parameter on every existing constructor | named `options` | named `serializerOptions` | `options` now names the stage's options record on every stage in the fleet. Binary-compatible; affects only callers that pass the argument **by name** (`options: x` → `serializerOptions: x`) |

---

## Deprecations

| Deprecated API | Replacement | Removed In |
|----------------|-------------|------------|
| `JsonLineExtractor<T>.Encoding` setter | `JsonLineExtractorOptions.Encoding` | a later release, after this deprecation has shipped |
| `JsonLineExtractor<T>.EnableCheckpointing` setter | `JsonLineExtractorOptions.EnableCheckpointing` | same |
| `JsonLineExtractor<T>.StartByteOffset` setter | `JsonLineExtractorOptions.StartByteOffset` | same |
| `JsonLineLoader<T>.Encoding` setter | `JsonLineLoaderOptions.Encoding` | same |
| `JsonLineLoader<T>.IsDryRun` setter | `JsonLineLoaderOptions.IsDryRun` | same |
| `JsonSingleStreamLoader<T>.IsDryRun` setter | `JsonSingleStreamLoaderOptions.IsDryRun` | same |
| `JsonMultiStreamLoader<T>.IsDryRun` setter | `JsonMultiStreamLoaderOptions.IsDryRun` | same |

Only the **setter** accessor is `[Obsolete]`; reading the properties stays warning-free.

Two groups of constructors are hidden from IntelliSense (`[EditorBrowsable(Never)]`) but **retained permanently** for binary compatibility. Positional calls keep compiling and keep binding to them (the second group is also subject to the `serializerOptions` rename above if the argument was passed by name); new code has no reason to name them:

- the single-argument constructors (`(Stream)`, `(IEnumerable<Stream>)`, `(IEnumerable<JsonNamedStream>)`, `(Func<T, Stream>)`, `(Func<T, JsonNamedDestination>)`), superseded by the optional-logger overloads;
- the `(source, JsonSerializerOptions?, ILogger?)` constructors, superseded by the record constructors below (`SerializerOptions` on the record).

---

## The new shape: one options record per stage

Every stage gains a sealed record that carries its construction-time configuration, inheriting the settings every extractor or loader shares from `Wolfgang.Etl.Abstractions`:

| Stage | Record | Own members | Inherited |
|-------|--------|-------------|-----------|
| `JsonLineExtractor<T>` | `JsonLineExtractorOptions` | `SerializerOptions`, `Encoding`, `EnableCheckpointing`, `StartByteOffset` | `ReportingInterval`, `MaximumItemCount`, `SkipItemCount`, `ErrorPolicy` |
| `JsonSingleStreamExtractor<T>` | `JsonSingleStreamExtractorOptions` | `SerializerOptions` | same |
| `JsonMultiStreamExtractor<T>` | `JsonMultiStreamExtractorOptions` | `SerializerOptions` | same |
| `JsonLineLoader<T>` | `JsonLineLoaderOptions` | `SerializerOptions`, `Encoding`, `IsDryRun` | same |
| `JsonSingleStreamLoader<T>` | `JsonSingleStreamLoaderOptions` | `SerializerOptions`, `IsDryRun` | same |
| `JsonMultiStreamLoader<T>` | `JsonMultiStreamLoaderOptions` | `SerializerOptions`, `IsDryRun` | same |

`SerializerOptions` on the record configures the reflection-based serializer. The source-generated constructors take a `JsonTypeInfo<T>` as their own parameter instead, because the type info already carries its own options; a record that also sets `SerializerOptions` is rejected by those constructors with `ArgumentException`.

The record is passed right after the source and is required on the new constructors:

```csharp
// before (v0.8)
var extractor = new JsonLineExtractor<Person>(stream, serializerOptions)
{
    EnableCheckpointing = true,
    MaximumItemCount = 1_000,
};

// after (v0.9)
var extractor = new JsonLineExtractor<Person>
(
    stream,
    new JsonLineExtractorOptions
    {
        SerializerOptions = serializerOptions,
        EnableCheckpointing = true,
        MaximumItemCount = 1_000,
    }
);

// source-generated: the record follows the type info
var aot = new JsonLineExtractor<Person>(stream, AppJsonContext.Default.Person, new JsonLineExtractorOptions { SkipItemCount = 10 });
```

A stage constructed without a record keeps every default, exactly as before.

## Checklist

- [ ] Replace `options:` with `serializerOptions:` wherever a `JsonSerializerOptions` is passed by name.
- [ ] Drop `ISupportDryRun` from any code that referenced it; configure dry run through the loader's record.
- [ ] Move post-construction assignments to the seven deprecated setters into the matching options record (the compiler warning names it).
