Remarks

This stage has no settings of its own; the record exists so the settings every extractor shares (inherited from Wolfgang.Etl.Abstractions.ExtractorOptions) are configured the same way as on every other stage. SerializerOptions configures the reflection-based deserializer. The source-generated path takes a JsonTypeInfo<TRecord> as its own constructor parameter instead, because the type info carries its own serializer options; a record that sets SerializerOptions is rejected by those constructors rather than silently ignored.
