Remarks

Carries the settings specific to this stage together with the ones every loader shares (inherited from Wolfgang.Etl.Abstractions.LoaderOptions), so one object configures the whole stage. SerializerOptions configures the reflection-based serializer. The source-generated path takes a JsonTypeInfo<TRecord> as its own constructor parameter instead, because the type info carries its own serializer options; a record that sets SerializerOptions is rejected by those constructors rather than silently ignored.
