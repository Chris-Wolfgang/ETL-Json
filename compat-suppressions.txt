# ApiCompat suppressions for Wolfgang.Etl.Json.
#
# One entry per line — a CP-code prefix (e.g. CP0001) or a substring of the
# apicompat message that uniquely identifies the intentional break.
# Lines starting with '#' are comments and are ignored.
#
# Example:
#   CP0002: Member 'SomeMethod()' exists in the contract but not in the implementation
#
# Entries here have a SHELF LIFE. scripts/Check-ApiCompatibility.ps1 compares the
# current build against the highest version published below <Version> — so a
# suppression only does work while the break is visible across that one hop. Once
# a release ships without the removed API, the following release's comparison no
# longer sees the break and the entry becomes dead weight. Prune entries when the
# release that introduced them is no longer the comparison baseline, so this file
# never accumulates rules that quietly match something they were not written for.
#
# (The 0.9.0 ISupportDryRun entry was pruned when 0.10.0 made 0.9.0 the comparison
# baseline: 0.9.0 already lacks the interface, so the rule could no longer match the
# break it was written for - only some future one of the same shape.)
